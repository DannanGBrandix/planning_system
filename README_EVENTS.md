# Brandix Embellishment Plan - Event Codes

This document lists all the event codes used in the Embellishment Plan system, categorized by their phase and purpose.

## Sample & Sewing Events (Milestones)
These events are tracked separately on the Fabric Dispatch page under the **Sample & Sewing Schedule** table.
* **CSRF**: Sample request form to send cut panel (we send this to sample room)
* **CPS**: Cut panel sending to plants
* **SEWIN**: Garment sample request form (sent to sample room)
* **SEWS**: Garment sewing starts
* **GMT**: Garment sending (pillowcase)
* **GSD**: Garment sending to dye
* **AWR**: Art work receive

## Internal / Approval Events
* **NY**: Dispatch sample to New York
* **NYC**: Customer comments received
* **MAST**: Dispatching to regional teams (MAST)
* **REAP**: Regional approval
* **FCHP**: Final checkpoint / shopping
* **REAP/FCHP**: Regional approval + final checkpoint
* **RFIT**: Fit on to a model
* **ADP**: ADP event
* **NYC/DRP**: NYC with drop
* **PLSA**: PLSA event

## External / Plant Events
These represent standard events where components are moving between branches or plants.
* **FS**: First sample
* **PPS**: Print panel / strike-off sending to branch
* **FR**: Fabric received
* **RDPS**: Return dye panel to another plant
* **PPSDS**: Print panel sending to dye plants
* **PPSES**: Print panel sending to emb plant

## Testing Events
* **DTC-3010 / LTD-37**: Standard Testing
* **CK TEST**: CK check test
* **BIA**: BIA event
* **PPR**: PPR event

---
*Note: This list includes all base codes used for planning and tracking across the main application and dispatch views.*
